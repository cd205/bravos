<objective>
Session 3 (3a + 3b) from `.planning/IMPLEMENTATION_PLAN.md`: give `IBApp` a public API
(`get_nlv`, `get_daily_pnl`, `fetch_delayed_price`, `place_order_and_wait`) so

two near-identical submit paths in `executor.py` onto shared helpers so the Session-1a
status-wait protocol lives in exactly one place.

a silent behavioural change to the DB-write sequence (the same one Session 1a fixed after
two real masked rejections). **Behaviour-identical is the hard requirement.** The value is
structural: renaming an IBApp field can no longer break distant files with no type error,
and IMPROVEMENTS bug #3 no longer has to be fixed in two copies.

Output: `IBApp` public API + `OrderResult`; a slimmer `executor.py` reading as pure
business logic; `gate.py` reading NLV/PnL through the seam; focused pure-mock tests for the
new API; grep-gate proving no private reach-ins remain in `executor.py`/`gate.py`.
</objective>

## executor.py logic being moved/absorbed (behaviour to preserve EXACTLY)

`_fetch_price(ticker, ibapp)` — allocate req_id under `_tick_lock`, install
`{"event", "price": None}` slot, `reqMarketDataType(3)`, `reqMktData(req_id, contract, "", False, False, [])`,
`slot["event"].wait(PRICE_WAIT_TIMEOUT)`, return `slot["price"]` or None, **always**
`cancelMktData(req_id)` in finally + pop slot under lock.

`_resolve_db_status(slot, order_id)` — IBKR_ERROR -> "REJECTED" (log ERROR w/ code+message);
`status is None` -> "UNKNOWN" (log ERROR "unverified"); else `_STATUS_MAP.get(raw, "UNKNOWN")`.
`_STATUS_MAP = {"PreSubmitted":"SUBMITTED","Submitted":"SUBMITTED","Inactive":"REJECTED"}`.

`_calculate_quantity` NLV read: `(ibapp._account_summary or {}).get("NetLiquidation", "0")`
then `float(...)` with TypeError/ValueError -> log + return 0.

`gate._read_nlv(ibapp)`: `getattr(ibapp,"_account_summary",None) or {}`, `.get("NetLiquidation")`,
None -> None, `float(raw)` with TypeError/ValueError -> log warning + None.
`gate.check` daily_pnl: `getattr(ibapp,"_daily_pnl",None) if ibapp is not None else None`.
