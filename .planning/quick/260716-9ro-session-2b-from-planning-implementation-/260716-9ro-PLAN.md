**THE STALE-NAME-BINDING TRAP (why option (a), not a re-export):**
`from bravos.runtime import ibapp` in connection.py would bind connection's
`ibapp` NAME to the object runtime.ibapp pointed at IMPORT time (None).
Every later reassignment of `runtime.ibapp` (initial connect, every
SIGUSR2 resume, every execute_pending run) would be invisible through the
re-export — the executor would see a permanent stale None and silently skip
every order. Therefore: canonical state lives in `runtime.ibapp`; the
executor reads `runtime.ibapp` at call time; connection.py keeps a plain
`ibapp = None` attribute that the SAME writers mirror-write during the
transition release. No `from`-import re-export anywhere.
