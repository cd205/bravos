<objective>
Fix IBKR error 10268 ("The 'EtradeOnly' order attribute is not supported"): ibapi 9.81.1-1's `Order()` constructor defaults `eTradeOnly=True` and `firmQuoteOnly=True`, and IB Gateway 1045+ rejects any placeOrder carrying these deprecated attributes. Set both to `False` explicitly at every Order construction site in the executor.

Purpose: This is the last known blocker between a parsed signal and an accepted paper order. Confirmed in production 2026-07-08 05:24 UTC — MKT BUY 107 HROW (signal_id=2553) was rejected with error 10268 and never reached the account. Until fixed, EVERY order (plain MKT and all bracket legs) will be rejected.

Output: Patched `bravos/execution/executor.py` (4 Order sites) + regression tests in `tests/test_execution.py`.
</objective>
