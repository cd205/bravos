<objective>
Fix the Chrome driver crash death-loop confirmed in production on 2026-07-07: a dead
chromedriver raises urllib3 MaxRetryError (not WebDriverException), which escapes
_check_session() and run_cycle(), lands in the main-loop guard, and — because schedule
never records the run — re-fires every second for ~24h while blocking the 06:00 nightly
restart and 14:30 RiskGate reset.

Purpose: Make the health-check path crash-safe and self-healing so a dead driver recovers
on the next 300s cycle instead of blinding the scraper until manual restart.

Output: Crash-safe _check_session() (scraper.py), crash-safe self-healing run_cycle() that
reuses the existing driver-recreation primitive (run_ingestion.py), and regression tests.
</objective>
